# InsightDash Web

## Rodar no computador
1. Instale Python 3.11+.
2. Abra um terminal nesta pasta.
3. Execute:
   pip install -r requirements.txt
4. Execute:
   streamlit run app.py
5. Abra o endereço mostrado pelo Streamlit.

## Colocar online
A opção mais simples para este protótipo é o Streamlit Community Cloud:
- coloque estes arquivos em um repositório GitHub;
- conecte o repositório ao Streamlit Community Cloud;
- selecione `app.py`;
- faça o deploy.

## Importante
Esta versão é um protótipo web funcional. Para produção comercial, adicione autenticação, banco de dados, armazenamento privado, limites de upload, isolamento por cliente, logs, rate limiting e gerenciamento de segredos.
